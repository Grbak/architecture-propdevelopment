# Требования к внешней интеграции

1. Внешним системам должен передаваться минимальный набор данных
2. Обрабатываемые внешними системами персональные данные должны быть обезличены
3. Обрабатывающие персональные данные внешние системы должны соответствовать требованиям законодательства в сфере ИБ
4. Должен проводиться регулярный аудит передаваемых внешним системам данных
5. Любые данные должны передаваться внешней системе в зашифрованном виде
6. Внутри внешней системы передаваемые данные должны передаваться в зашифрованном виде
7. Внешние системы должны использовать передаваемые данные только по назначению и не должны ни передавать их третьим лицам, ни сохранять их в каком-либо виде после использования
8. Используемый для интеграции API должен подразумевать аутентификацию каждого входящего запроса с использованием протокола OAuth или API-токенов
9. Для защиты от DoS-атак обрабатывающие внешние запросы сервисы должны подразумевать внедрение рейт-лиимеров
10. Для предовтращения ошибок в системе в случае отказа внешней системы стоит рассмотреть использование паттерна Circuit Breaker
